# Камтуу

`diff`'тен өтүү порт ар бир жазылган кейске дал келет дегенди билдирет. Камтуу ошол кейстер түп нусканын канчасын иштеткенин айтат, ошентип жазуу эмнени камтыбай турганын билесиз.

TypeScript/JavaScript үчүн `record` V8'тин камтуу маалыматы аркылуу кейстер түп нусканын кайсы саптарын иштеткенин өлчөйт, ал эми `gate` аны өтүүчү, маалымат берүүчү текшерүү катары чыгарат: жеткен саптардын үлүшү жана эң көп сап өткөрүлүп жиберилген файлдар. Башка тилдер аны азырынча өлчөбөйт.

Fuse.js'те кейстер бирдик импорттогон саптардын 81%ын иштетти ([абалы](/docs/project/status)).

## Аны жогорулатуу

Кейстер эч качан жетпеген саптар эч ким текшербеген жүрүм-турум. Аларга төмөнкүлөр менен жетиңиз:

- `record --from-tests -- <test command>`, түп нусканын өзүнүн тесттери жасаган ар бир чакырууну жазып алуу үчүн;
- `record --inputs`, генерацияланган киргизүүлөр жете албаган жолдорго кирген чыныгы киргизүүлөр менен (структуралык аргументтер, домендик саптар).

[Жазып алуу](/docs/concepts/record) жана [Ал эмнени кармай албайт](/docs/concepts/limits) барактарын караңыз.
