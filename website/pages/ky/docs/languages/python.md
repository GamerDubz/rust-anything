# Python

| | |
| --- | --- |
| Бирдик | пакет же модуль |
| Bridge | PyO3 (abi3), түз айландыруу, типтелген exception'дор |
| Ким жазып алат жана кайра ойнотот | Python, түп нусканы импорттойт |
| Керектүү | Python 3.9+ |
| Абалы | CPython 3.13'төгү `colorsys.py`'да текшерилген: 2,400/2,400, gate өтөт |

Типтер type hint'терден алынат. Сан катары колдонулган типсиз параметрлер (`r - g`, `max(r, g, b)`, `x < 1`) сан деп эсептелет. `record --from-tests -- pytest` түп нусканын өзүнүн тесттери жасаган ар бир чакырууну жазып алат (Tested).

## Порт эмнени туура жасашы керек

- Python чакыруучулары `1`'ди `1.0` сыяктуу эле көп беришет, жана int'тер өзгөрүүсүз өтөт. Жазуу кейстердин ар бир төртүнчүсүндө бүтүн сандарды int катары берет; `f64` деп типтелген порт int'тер жазылып алынганда 134 дал келбестик көрсөттү. int-же-float үчүн `crate::pynum::Num` колдонуңуз.
- `max(nan, 1, 2)` `nan` болот: кийинки маани чоңураак деп салыштырылмайынча биринчи маани утат.
- `-0.0 % 1.0` `0.0` болот.
- `Err("TypeName: message")` катары кайтарылган каталар ошол exception'го айланат.

numba, Cython же JAX буга чейин компиляциялаган код машиналык код катары иштейт: `profile` жана `analyze` аны белгилейт, анткени аны порттоо ылдамдыкты аз гана кошот.

## Ылдамдык

Rust'ка чакыруу болжол менен 100-300 ns турат жана Rust коду интерпретатордон алда канча ылдам, ошондуктан кичинекей функциялар да утат. `colorsys`'те `bench` портту бир чакырууга CPython'дон **1.35x ылдамыраак** деп өлчөдү (көпчүлүк чакырууларда 1.5-1.9x). Batch катары 20,000 саптагы `slugify` 4 ядродо 98 ms'тен **17x ылдамыраак** болду.
