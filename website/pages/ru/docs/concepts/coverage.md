# Покрытие

Прохождение `diff` означает, что порт совпадает с каждым записанным кейсом. Покрытие показывает, какую часть оригинала выполнили эти кейсы, чтобы вы знали, что запись не охватывает.

Для TypeScript/JavaScript `record` измеряет строки оригинала, выполненные кейсами, по данным покрытия V8, а `gate` выводит это как проходящую информационную проверку: долю достигнутых строк и файлы с наибольшим числом пропущенных строк. Другие языки пока это не измеряют.

На Fuse.js кейсы выполнили 81% строк, которые импортирует модуль ([статус](/docs/project/status)).

## Как его повысить

Строки, до которых кейсы никогда не доходят, это поведение, которое никто не проверил. Доберитесь до них с помощью:

- `record --from-tests -- <test command>`, чтобы записать каждый вызов, который делает собственный набор тестов оригинала;
- `record --inputs` с реальными входными данными, которые проходят по путям, пропущенным сгенерированными (структурированные аргументы, строки предметной области).

См. [Запись (record)](/docs/concepts/record) и [Чего он не поймает](/docs/concepts/limits).
