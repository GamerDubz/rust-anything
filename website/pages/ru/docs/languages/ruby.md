# Ruby

| | |
| --- | --- |
| Модуль | файл или каталог с функциями модуля |
| Мост | расширение magnus в исходных модулях |
| Чем записывается и воспроизводится | сгенерированный Ruby-драйвер |
| Требуется | Ruby 3+ |
| Статус | Проверен на `shellwords.rb` из Ruby 3.3: 1,617/1,617 (446 с raise), gate проходит |

Типы берутся из тегов YARD; нетипизированные параметры, используемые как числа, выводятся как числовые. Пакеты создаются как `Mod::FnBatch.new(items)`, и элементы пакета могут быть любыми значениями.

## Что порт должен сделать правильно

- `downcase` переводит в нижний регистр каждый символ отдельно, без правила конечной сигмы из Rust.
- `Array#sum` использует суммирование Кэхэна-Бабушки и начинает с целого 0, поэтому `[-0.0].sum` равно `0.0`.
- `Float#to_s` использует экспоненциальную запись начиная с 1e15 (`1e15.to_s` даёт `1.0e+15`, `1e14.to_s` даёт `100000000000000.0`); `nil.inspect` внутри массивов даёт `nil`.
- Динамическая типизация стоит кода: порт `shellwords` заново реализует `to_s` и `inspect` из Ruby для чисел, nil, массивов и хешей, потому что `shellescape` принимает что угодно.

## Скорость

Интерпретатор достаточно медленный, чтобы выигрывали даже маленькие функции. На `shellwords` `bench` намерил порт **в 4.4x быстрее** Ruby на вызов (3.6-7x на функцию). В виде пакетов на 4 ядрах: `Shellwords.shellescape` на 50,000 смешанных значений (88 ms в Ruby) работал **в 11.8x быстрее**, а `slugify` на 20,000 строк (110 ms) **в 12.7x**.
