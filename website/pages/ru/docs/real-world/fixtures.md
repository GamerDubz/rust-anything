# Фикстуры и статические прогоны

## Фикстуры, написанные для нагрузочной проверки инструмента

| Фикстура | Что проверяет | Результат |
| --- | --- | --- |
| `tests/fixtures/async` | async-функции на обоих мостах | 900/900, оба гейта проходят |
| `tests/fixtures/classes` | классы: состояние, ошибки конструктора, порядок `Map`, `split('')` на эмодзи | 600/600 сценариев, оба гейта проходят |
| `tests/fixtures/aliases` | `paths` в tsconfig с `extends`, комментарии, висячие запятые | analyze и record следуют им |
| `tests/fixtures/monorepo` | пакет, импортирующий соседний пакет без результатов сборки | record разрешает его в исходники |

Найдено в инструменте и исправлено: napi превращал `None` в `null` (JS даёт `undefined`); сценарии
были слишком короткими и слишком случайными, чтобы поймать баг состояния (теперь до 12 вызовов с повторным использованием прежних строк);
генерировались `let out = ()` и немедленно вызываемые замыкания, которые отвергает clippy.
## Внешние библиотеки (только статически)

`unjs/scule`, `unjs/ufo` и `unjs/pathe` были клонированы, проанализированы и подключены через мост. Запуск их
кода (`record` выполняет оригинал) был запрещён политикой безопасности сессии для кода,
скачанного из интернета, поэтому эти прогоны останавливаются перед `record`.

| Библиотека | analyze | bridge |
| --- | --- | --- |
| scule (преобразование регистра) | 2 модуля, готовы | все 11 функций можно подключить через мост после исправления ниже |
| ufo (утилиты для URL) | 7 модулей, готовы; `punycode.ts` на первом месте | `toASCII` подключён через мост (нетипизированный JS: передаётся как JSON) |
| pathe (утилиты для путей) | 5 модулей; `_glob.ts` с предупреждением (динамическое регулярное выражение) | 13 функций подключены через мост; экспорты с типом `typeof path.join` передаются как JSON |

Найдено в инструменте и исправлено: ограниченные дженерики (`camelCase<T extends string | readonly
string[]>`) считались «любым значением, включая функции», из-за чего 10 из 11
функций scule оставались на TS. Параметры типа с ограничениями на данные теперь заменяются этим ограничением.

Порт scule был написан (`demo` не включён: его ни разу не записывали против оригинала).
