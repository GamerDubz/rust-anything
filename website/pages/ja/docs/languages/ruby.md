# Ruby

| | |
| --- | --- |
| ユニット | モジュール関数を含むファイルまたはフォルダ |
| ブリッジ | 元のモジュール配下に置かれる magnus 拡張 |
| 記録とリプレイの実行方法 | 自動生成の Ruby ドライバー |
| 必要なもの | Ruby 3+ |
| ステータス | Ruby 3.3 の `shellwords.rb` で検証済み: 1,617/1,617（446 件は例外を投げる）、gate に合格 |

型は YARD タグから取得します。型のない引数で数値として使われているものは数値と推論されます。バッチは `Mod::FnBatch.new(items)` で、バッチの要素には任意の値を使えます。

## 移植版が正しく扱うべきこと

- `downcase` は各文字を個別に小文字化し、Rust の語末シグマのルールは適用しません。
- `Array#sum` は Kahan-Babuska の総和を使い、整数 0 から始めるので、`[-0.0].sum` は `0.0` です。
- `Float#to_s` は 1e15 以上で指数表記を使います（`1e15.to_s` は `1.0e+15`、`1e14.to_s` は `100000000000000.0`）。配列内の `nil.inspect` は `nil` です。
- 動的型付けはコード量に響きます: `shellescape` は何でも受け付けるので、`shellwords` の移植版は数値、nil、配列、ハッシュについて Ruby の `to_s` と `inspect` を再実装しています。

## 速度

インタプリタが十分に遅いので、小さな関数でも速くなります。`shellwords` では、`bench` の計測で移植版は呼び出しごとに Ruby より **4.4 倍高速**でした（関数ごとに 3.6-7 倍）。4 コアのバッチでは、50,000 個の混在値に対する `Shellwords.shellescape`（Ruby で 88 ms）が **11.8 倍高速**、20,000 文字列に対する `slugify`（110 ms）が **12.7 倍**でした。
