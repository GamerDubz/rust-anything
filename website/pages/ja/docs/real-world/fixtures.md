# フィクスチャと静的実行

## ツールに負荷をかけるために書いたフィクスチャ

| フィクスチャ | 検証内容 | 結果 |
| --- | --- | --- |
| `tests/fixtures/async` | 両方のブリッジでの async 関数 | 900/900、両方のゲートに合格 |
| `tests/fixtures/classes` | クラス: 状態、コンストラクターのエラー、`Map` の順序、絵文字に対する `split('')` | 600/600 シナリオ、両方のゲートに合格 |
| `tests/fixtures/aliases` | `extends`、コメント、末尾カンマを含む tsconfig の `paths` | analyze と record がそれをたどる |
| `tests/fixtures/monorepo` | ビルド出力のない兄弟パッケージをインポートするパッケージ | record がソースに解決する |

ツールで見つかり、修正されたもの: napi が `None` を `null` に変換していた（JS は `undefined` を返す）。シナリオが
短すぎ、ランダムすぎて、状態に依存するバグを捕まえられなかった（現在は最大 12 回の呼び出しで、前の文字列を再利用する）。
clippy が拒否する `let out = ()` や即時呼び出しのクロージャを生成していた。
## 外部ライブラリ（静的のみ）

`unjs/scule`、`unjs/ufo`、`unjs/pathe` をクローンして分析し、ブリッジしました。そのコードの実行
（`record` は元の実装を実行します）は、インターネットからダウンロードしたコードに対するセッションの安全ポリシーにより
拒否されたため、これらの実行は `record` の前で止まっています。

| ライブラリ | analyze | bridge |
| --- | --- | --- |
| scule（大文字小文字の変換） | 2 ユニット、準備完了 | 下記の修正後、11 関数すべてがブリッジ可能 |
| ufo（URL ユーティリティ） | 7 ユニット、準備完了。`punycode.ts` が 1 位 | `toASCII` をブリッジ（型のない JS: JSON として境界を越える） |
| pathe（パスユーティリティ） | 5 ユニット。`_glob.ts` は要注意（動的な正規表現） | 13 関数をブリッジ。`typeof path.join` 型のエクスポートは JSON として境界を越える |

ツールで見つかり、修正されたもの: 制約付きジェネリクス（`camelCase<T extends string | readonly
string[]>`）が「関数を含む任意の値」として扱われ、scule の 11 関数のうち 10 関数が
TS に残っていました。データの制約を持つ型パラメータは、現在はその制約で置き換えられます。

scule の移植版は書かれました（`demo` には含まれていません: 元の実装に対して記録されたことがないためです）。
