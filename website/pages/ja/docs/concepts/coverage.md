# カバレッジ

`diff` に合格したということは、移植版が記録されたすべてのケースに一致するということです。カバレッジは、それらのケースが元の実装をどれだけ実行したかを示すので、記録がカバーしていない部分がわかります。

TypeScript/JavaScript では、`record` が V8 のカバレッジから、ケースが実行した元の実装の行を計測し、`gate` がそれを合格扱いの参考情報として表示します: 到達した行の割合と、未到達の行が最も多いファイルです。他の言語ではまだ計測していません。

Fuse.js では、ケースがユニットのインポートする行の 81% を実行しました（[ステータス](/docs/project/status)）。

## カバレッジを上げる

ケースが一度も到達しない行は、誰も確認していない挙動です。次の方法で到達させます:

- `record --from-tests -- <test command>` で、元の実装自身のテストスイートが行うすべての呼び出しを記録する。
- `record --inputs` で、生成された入力では通らないパス（構造化された引数、ドメイン固有の文字列）を通る実際の入力を与える。

[記録](/docs/concepts/record)と[検出できないもの](/docs/concepts/limits)を参照してください。
