# Колачлау

`diff` узу портның язып алынган һәр очракка туры килүен аңлата. Колачлау шул очраклар оригиналның күпме өлешен җибәргәнен әйтә, шуңа күрә сез язма нәрсәне колачламаганын беләсез.

TypeScript/JavaScript өчен `record` V8 колачлавы ярдәмендә очраклар җибәргән оригинал юлларын үлчи, ә `gate` аны узучы, мәгълүмат өчен генә тикшерү итеп чыгара: ирешелгән юллар өлеше һәм иң күп юл калдырылган файллар. Башка телләр аны әлегә үлчәми.

Fuse.js'та очраклар берәмлек импортлаган юлларның 81% өлешен җибәрде ([халәт](/docs/project/status)).

## Аны арттыру

Очраклар беркайчан да барып җитмәгән юллар беркем дә тикшермәгән тәртип ул. Аларга болай барып җитегез:

- `record --from-tests -- <test command>`, оригиналның үз тест җыелмасы ясаган һәр чакыруны язып алу өчен;
- `record --inputs`, ясалганнары калдырган юлларга кереп китүче чын кертмәләр белән (структуралы аргументлар, өлкәгә хас юллар).

[Язып алу](/docs/concepts/record) һәм [Ул нәрсәне тотып кала алмый](/docs/concepts/limits) битләрен карагыз.
