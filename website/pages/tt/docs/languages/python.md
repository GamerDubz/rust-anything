Типлар type hints'тан алына. Сан итеп кулланылган типсыз параметрлар (`r - g`, `max(r, g, b)`, `x < 1`) сан дип чыгарыла. `record --from-tests -- pytest` оригиналның үз тест җыелмасы ясаган һәр чакыруны язып ала (Тикшерелгән).

## Порт нәрсәне дөрес эшләргә тиеш

- Python'да чакыручылар `1`'не `1.0` кебек үк еш бирә, һәм int'лар үзгәрешсез уза. Язып алу һәр дүртенче очракта бөтен кыйммәтле саннарны int итеп бирә; int'лар язып алынгач, `f64` типлы порт 134 туры килмәү күрсәтте. Int яки float өчен `crate::pynum::Num` кулланыгыз.
- `max(nan, 1, 2)` `nan` бирә: соңрак килгәне зуррак булып чыкмаса, беренче кыйммәт ота.
- `-0.0 % 1.0` `0.0` бирә.
- `Err("TypeName: message")` итеп кайтарылган хаталар шул исключениегә әйләнә.

numba, Cython яки JAX белән инде компиляцияләнгән код машина коды булып эшли: `profile` һәм `analyze` аны билгели, чөнки аны күчерү аз тизлек бирә.

## Тизлек

Rust'ка чакыру якынча 100-300 ns тора, ә Rust коды интерпретатордан күпкә тизрәк, шуңа күрә кечкенә функцияләр дә отыш бирә. `colorsys`'та `bench` портны бер чакыруга CPython'нан **1.35x тизрәк** дип үлчәде (күпчелек чакыруларда 1.5-1.9x). Batch итеп, 20,000 юлга `slugify` 4 ядрода 98 ms'тан **17x тизрәк** булды.
