# Python

| | |
| --- | --- |
| Бірлік | пакет немесе модуль |
| Bridge | PyO3 (abi3), тікелей түрлендіру, типтелген exception-дар |
| Жазып алатын және қайта ойнататын | Python, түпнұсқаны импорттайды |
| Қажет | Python 3.9+ |
| Күйі | CPython 3.13-тегі `colorsys.py` файлында тексерілген: 2,400/2,400, gate өтеді |

Типтер type hint-терден алынады. Сан ретінде қолданылатын типсіз параметрлер (`r - g`, `max(r, g, b)`, `x < 1`) сан деп есептеледі. `record --from-tests -- pytest` түпнұсқаның өз тест жиынтығы жасайтын әр шақыруды жазып алады (Tested).

## Порт нені дұрыс істеуі керек

- Python шақырушылары `1` мәнін `1.0` сияқты жиі береді, және int-тер өзгеріссіз өтеді. Жазып алу әр төртінші кейсте бүтін сандарды int ретінде береді; `f64` деп типтелген порт int-тер жазылғаннан кейін 134 сәйкессіздік көрсетті. Int-немесе-float үшін `crate::pynum::Num` қолданыңыз.
- `max(nan, 1, 2)` нәтижесі `nan`: кейінгі мән үлкенірек болып салыстырылмаса, бірінші мән ұтады.
- `-0.0 % 1.0` нәтижесі `0.0`.
- `Err("TypeName: message")` ретінде қайтарылған қателер сол exception-ға айналады.

numba, Cython немесе JAX арқылы компиляцияланып қойған код машиналық код ретінде орындалады: `profile` және `analyze` оны белгілейді, өйткені оны порттау жылдамдыққа аз пайда береді.

## Жылдамдық

Rust-қа шақыру шамамен 100-300 ns тұрады, ал Rust коды интерпретатордан әлдеқайда жылдам, сондықтан кішкентай функциялар да ұтады. `colorsys`-те `bench` порттың бір шақыруға CPython-нан **1.35x жылдамырақ** екенін өлшеді (шақырулардың көбінде 1.5-1.9x). Batch ретінде 20,000 жол бойынша `slugify` 4 ядрода 98 ms-тан **17x жылдамыраққа** жетті.
