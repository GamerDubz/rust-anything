# ئۇ نېمىلەرنى تۇتالمايدۇ

ئۆتۈش دېگەنلىك Rust نىڭ خاتىرىلەنگەن ھەر بىر ئەھۋالغا ماس كېلىدىغانلىقى، ئۇنىڭدىن ئارتۇق ئەمەس. قايتا يېزىشلارنى چاقىدىغان نەرسە
ئادەتتە خاتىرىنىڭ سىرتىدا بولىدۇ، شۇڭا چېگرىلارنىڭ قەيەردە ئىكەنلىكىنى بىلىڭ:

- **ھېچكىم خاتىرىلىمىگەن كىرگۈزۈشلەر.** ھاسىل قىلىنغان ئەھۋاللار، تۇزاقلار، ئەسلى نۇسخىنىڭ سىناق توپلىمى
  (`record --from-tests`) ۋە ئۆزىڭىزنىڭ `--inputs` ى يۇقىرى چەك. ھەقىقىي كىرگۈزۈشلەرنى قوشۇڭ (ئىشلەپچىقىرىش
  ئۈلگىلىرى، خاتالىق دوكلاتلىرى)؛ ئىشلەپچىقىرىشنى بۇزىدىغان ئىشلەتكۈچى كىرگۈزۈشى ھاسىل قىلغۇچ ئويلايدىغان نەرسە بولۇشى ناھايىتى ئاز.
- **ئالغا ئىلگىرىلىگەن ئەسلى نۇسخا.** `record` بىرلىك ھۆججەتلىرىنىڭ بارماق ئىزىنى ساقلايدۇ
  (`recorded-from.json`)؛ ئەسلى نۇسخا كېيىن ئۆزگەرسە، ئەسلى نۇسخىنىڭ ئىلگىرى قىلغىنىغا قارىتا ئۆتۈپ كېتىشنىڭ ئورنىغا،
  قايتا خاتىرىلىمىگۈچە `diff` ئاگاھلاندۇرىدۇ، `gate` مەغلۇپ بولىدۇ.
- **Regex لار.** `regex` crate ىدا lookaround ياكى backreference يوق، ھەتتا تۈزۈلىدىغان ئەندىزىمۇ
  ASCII بولمىغان تېكىستتىكى `\w`، `\b`، `\d` ۋە چوڭ-كىچىك ھەرپنى پەرقلەندۈرمەيدىغان ماسلاشتۇرۇشنى JS، Python ياكى Java دىن
  باشقىچە بىر تەرەپ قىلىشى مۇمكىن. `fancy-regex` قا ئالماشتۇرۇش ياكى ئەندىزىنى قايتا يېزىش خاتىرىلەنگەن ھەر بىر
  ئەھۋالدىن ئۆتۈپمۇ، تۈركچە چېكىتسىز `ı` ياكى نۆل كەڭلىكتىكى ئۇلىغۇچتا يەنىلا پەرقلىنىشى مۇمكىن. `record` regex
  تۇزاقلىرىنى (شۇلار، Kelvin بەلگىسى، ئۇزۇن s، ئەرەب-ھىندى رەقەملىرى، قۇر ئايرىغۇچلار، ئاخىرقى sigma)
  regex ئىشلىتىدىغان ھۆججەتتىكى ھەر بىر فۇنكسىيەگە قوشىدۇ، ئەمما ھەقىقىي ئەندىزىلىرىڭىزنى ھەقىقىي تېكىستتە fuzz قىلىڭ.
- **ئىجرالار ئارىسىدا ئۆزگىرىدىغان نەرسىلەر.** `record` ئەسلى نۇسخىنى ئىككى قېتىم ئىجرا قىلىپ، پەرقلەنگەننى ئايرىيدۇ:
  ئۆزگەرگەن قىممەتلەر (ۋاقىت، id) ئورۇنباسارغا ئايلىنىدۇ؛ باشقا تەرتىپتىكى ئوخشاش قۇرلار (hash map،
  پاراللېللىق) ھەر قانداق تەرتىپتە سېلىشتۇرۇلىدۇ، شۇڭا كۆچۈرمە يەنىلا دەل شۇ قۇرلارنى ھاسىل قىلىشى كېرەك؛
  قۇر سانىنىڭ پەرقلىنىشى `...` غا ئايلىنىدۇ، ئۇ ھەر قانداق نەرسىگە ماس كېلىدۇ. `record` ھەر بىر تۈرنى كۆرسىتىدۇ:
  ھەر بىرىگە قاراپ چىقىڭ، چۈنكى hash تەرتىپى ياكى پاراللېللىق پەرقى دەل كۆچۈرمىدە ھەقىقىي
  ئۆزگىرىدىغان نەرسە.
- **لەيلىمە سانلار.** ساندىن تېكىستكە فورماتلاش تىللار ئارىسىدا پەرقلىنىدۇ (`1e21`، `-0`، رەقەم سانى).
  تۇزاقلار بۇ قىممەتلەرنى ئۆز ئىچىگە ئالىدۇ، ئۇلار تامامەن ماس كېلىشى كېرەك؛ `--float-tolerance` پەقەت
  يېقىنلاشتۇرۇشنىلا كەچۈرىدۇ، فورماتلاشنى ھەرگىز كەچۈرمەيدۇ.
- **چىقىرىشتا بولمىغان ھەر قانداق نەرسە.** ۋاقىت، ئىچكى ساقلىغۇچ، يۈك ئاستىدىكى پاراللېللىق، ۋە stdout، stderr، چېكىنىش كودلىرى،
  يېزىلغان ھۆججەتلەر ۋە HTTP جاۋابلىرىدىن باشقا قوشۇمچە تەسىرلەر (تور چاقىرىقلىرى، ساندانلار،
  سىگناللار) سېلىشتۇرۇلمايدۇ.
- **باشقا سۇپىلار.** خاتىرە ھەرىكەتنى پەقەت ئۇنى ئىجرا قىلغان ماشىنىدىلا ئىسپاتلايدۇ. نەتىجىلىرى
  تىپ چوڭلۇقى، بايت تەرتىپى ياكى تەرجىمانغا باغلىق C كودى نىشاندا باشقىچە ھەرىكەت قىلىشى مۇمكىن؛ `analyze`
  شۇ سەۋەبتىن قاتتىق دېتالغا قارىتىلغان C نى C دا قالدۇرىدۇ.
