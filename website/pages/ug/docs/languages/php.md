# PHP (ئالدىن كۆرۈش)

| | |
| --- | --- |
| بىرلىك | فۇنكسىيەلەر ۋە `public static` مېتودلىرىدىن تەركىب تاپقان بىر قىسقۇچ |
| كۆۋرۈك | كېيىنكى قەدەم: C ABI ئۈستىدە PHP FFI |
| بۈگۈن | پۈتۈن ئەپلەر: CLI ۋە مۇلازىمېتىرلار (`php -S`) ئۈچۈن `app record`، `app replay` ۋە ئالدى ئىشىك |
| ھالىتى | ئالدىن كۆرۈش: پەقەت `analyze` ۋە پۈتۈن ئەپلەر؛ بىرلىكلەرنى تېخى كۆۋرۈكلىگىلى بولمايدۇ |

`analyze` بىر PHP ئەپىنى پىلانلايدۇ: Composer بوغچىلىرى ۋە PSR-4 ئاپتوماتىك يۈكلەش، بوش سېلىشتۇرۇش ۋە پۈتۈن ساننىڭ لەيلىمە سانغا تېشىپ كېتىشى قاتارلىق خەتەرلەر، شۇنداقلا crate لارغا ماسلاشتۇرۇلغان Composer بوغچىلىرى. تىپلار PHP تىپلىرى ۋە phpdoc تىن كېلىدۇ.

PHP CLI ياكى مۇلازىمېتىرىنى خاتىرىلەپ، قايتا قويۇپ، Rust ئالدى ئىشىكى ئارقىسىغا قويغىلى بولىدۇ:

```sh
rust-anything app record . -- php cli.php
rust-anything app record . --http -- php -S 127.0.0.1:{port} router.php
rust-anything app replay .
rust-anything app front-door .
```

ئۇنىڭ بىرلىكلىرىنى PHP نىڭ FFI ى ئارقىلىق Rust قا كۆچۈرۈش كېيىنكى قەدەم ([issue #2](https://github.com/erkamyaman/rust-anything/issues/2)). ئۇنىڭغىچە `bridge` PHP بىرلىكلىرىنى ئېنىق ئۇچۇر بىلەن رەت قىلىدۇ.

CI PHP نى ئورناتمايدۇ، شۇڭا PHP سىناقلىرى پەقەت ئۇ ئورنىتىلغان ماشىنىدىلا ئىجرا بولىدۇ.
