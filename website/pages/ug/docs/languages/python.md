# Python

| | |
| --- | --- |
| بىرلىك | بىر بوغچا ياكى مودۇل |
| كۆۋرۈك | PyO3 (abi3)، بىۋاسىتە ئايلاندۇرۇش، تىپلىق مۇستەسنالار |
| خاتىرىلەيدىغان ۋە قايتا قويىدىغىنى | ئەسلى نۇسخىنى import قىلىدىغان Python |
| كېرەكلىكى | Python 3.9+ |
| ھالىتى | CPython 3.13 تىكى `colorsys.py` دا دەلىللەنگەن: 2,400/2,400، gate ئۆتىدۇ |

تىپلار تىپ ئىشارەتلىرىدىن كېلىدۇ. سان سۈپىتىدە ئىشلىتىلگەن تىپسىز پارامېتىرلار (`r - g`، `max(r, g, b)`، `x < 1`) سان دەپ پەرەز قىلىنىدۇ. `record --from-tests -- pytest` ئەسلى نۇسخىنىڭ ئۆز سىناق توپلىمى قىلغان ھەر بىر چاقىرىقنى خاتىرىلەيدۇ (سىنالغان).

## كۆچۈرمە نېمىنى توغرا قىلىشى كېرەك

- Python چاقىرغۇچىلىرى `1` نى `1.0` چەكلىك دائىم يەتكۈزىدۇ، int لار ئۆز پېتى ئۆتىدۇ. خاتىرىلەش ھەر تۆتىنچى ئەھۋالدا پۈتۈن سانلارنى int قىلىپ يەتكۈزىدۇ؛ `f64` تىپلىق بىر كۆچۈرمە int لار خاتىرىلەنگەندىن كېيىن 134 ماس كەلمەسلىكنى كۆرسەتتى. int ياكى float ئۈچۈن `crate::pynum::Num` نى ئىشلىتىڭ.
- `max(nan, 1, 2)` نىڭ قىممىتى `nan`: كېيىنكىسى چوڭراق دەپ سېلىشتۇرۇلمىسا، بىرىنچى قىممەت غالىب كېلىدۇ.
- `-0.0 % 1.0` نىڭ قىممىتى `0.0`.
- `Err("TypeName: message")` بولۇپ قايتۇرۇلغان خاتالىقلار شۇ مۇستەسناغا ئايلىنىدۇ.

numba، Cython ياكى JAX ئارقىلىق ئاللىقاچان تۈزۈلگەن كود ماشىنا كودى بولۇپ ئىجرا بولىدۇ: `profile` ۋە `analyze` ئۇنى بەلگىلەيدۇ، چۈنكى ئۇنى كۆچۈرۈش ئاز سۈرئەت ئېلىپ كېلىدۇ.

## سۈرئەت

Rust قا چاقىرىش تەخمىنەن 100-300 ns، Rust كودى ئىزاھلىغۇچتىن خېلىلا تېز، شۇڭا كىچىك فۇنكسىيەلەرمۇ ئۇتىدۇ. `colorsys` تا `bench` كۆچۈرمىنى ھەر چاقىرىشتا CPython دىن **1.35x تېز** دەپ ئۆلچىدى (كۆپ چاقىرىشلاردا 1.5-1.9x). توپ سۈپىتىدە، 20,000 قۇر ئۈستىدىكى `slugify` 4 يادرودا 98 ms دىن **17x تېز** غا يەتتى.
